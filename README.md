# Roam India – Places to Remember

A simple and visually appealing travel website for exploring memorable destinations across India.

## Project Overview

**Roam India** is a frontend web project designed to give users a quick visual introduction to some of India's famous destinations.

The website features:

* Taj Mahal – Agra, Uttar Pradesh
* Pink City – Jaipur, Rajasthan
* River of Light – Varanasi, Uttar Pradesh
* Stones of Time – Hampi, Karnataka

It also includes **Book Now**, **Explore More**, and **Get App** sections for future travel-booking and application integration.

## Features

* Clean and modern travel-themed UI
* Responsive design for desktop, tablet, and mobile
* Destination cards with high-quality images
* Location details for each destination
* Tour booking section
* Get App section
* Contact information section
* Hover effect on destination images
* External destination images using Unsplash

## Technologies Used

* HTML5
* CSS3
* Responsive Web Design
* Unsplash Images

## Website Sections

### 1. Hero Section

Introduces the website with the tagline:

> **India, unfolded.**

It provides a visual introduction to the travel experience.

### 2. Tour Booking Section

Users can access:

* **Book Now**
* **Explore More**

These buttons currently redirect to the booking page.

### 3. Featured Destinations

The website showcases four destinations:

| Destination    | Location                |
| -------------- | ----------------------- |
| Taj Mahal      | Agra, Uttar Pradesh     |
| Pink City      | Jaipur, Rajasthan       |
| River of Light | Varanasi, Uttar Pradesh |
| Stones of Time | Hampi, Karnataka        |

### 4. Get The App

A dedicated section is provided for a future travel application where users can explore more destinations and plan trips.

### 5. Contact Section

The footer contains contact information and copyright details.

## Responsive Design

The website adapts its layout based on screen size:

* Desktop
* Tablet
* Mobile

CSS media queries are used to adjust the hero section, destination grid, typography, and layout for smaller screens.

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/roam-india.git
```

2. Open the project folder.

3. Open `project.html` in any modern web browser.

4. Make sure `booking.html` is present in the same folder for the booking links to work.
